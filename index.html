Konfiguration fehlt noch

Die Datei ist noch nicht mit deinem Supabase-Projekt verbunden. Öffne index.html in einem Editor und trage oben im Bereich CONFIG deine echten Werte ein:

const CONFIG = { supabaseUrl: 'https://DEIN-PROJEKT.supabase.co', supabaseAnonKey: 'DEIN-ANON-ODER-PUBLISHABLE-KEY' };

Beide Werte findest du in deinem Supabase-Projekt unter Project Settings → API.
